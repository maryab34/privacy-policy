# Gizlilik Politikası — Facebook Sayfa Post Otomasyonu

Bu uygulama, kullanıcının kendi yönetimindeki Facebook Sayfalarına otomatik içerik
paylaşmak için kullanılır.

## Toplanan Veriler

- Facebook Sayfa kimlikleri ve sayfa adları
- Sayfa access token'ları (yalnızca post paylaşımı ve metrik okuma için)
- Paylaşılan gönderilerin metin ve görsel içerikleri
- Gönderi etkileşim metrikleri (beğeni, yorum, paylaşım sayıları)

## Verilerin Kullanımı

- Toplanan veriler YALNIZCA kullanıcının kendi sayfalarında içerik paylaşımı ve
  paylaşım performansının ölçülmesi için kullanılır.
- Veriler üçüncü taraflarla paylaşılmaz, satılmaz, reklam amaçlı kullanılmaz.
- Veriler kullanıcının kendi bilgisayarında lokal olarak saklanır.

## Veri Silme

Kullanıcı dilediği zaman Facebook hesap ayarlarından uygulamanın erişimini
kaldırarak tüm token erişimini geçersiz kılabilir. Lokal veriler kullanıcı
tarafından dilediği zaman silinebilir.

## Veri Güvenliği

Access token'lar şifreli olarak, yalnızca kullanıcının kendi cihazında saklanır
ve hiçbir harici servise gönderilmez.
